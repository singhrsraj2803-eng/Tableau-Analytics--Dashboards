# 📊 Tableau Analytics Dashboards

This repository contains interactive **Tableau dashboards** created to analyze retail and sales performance using data visualization techniques.

The dashboards provide insights into **revenue trends, profit analysis, product performance, and regional sales distribution.**

---

# 📌 Dashboards Included

## 🍎 Apple Retail Performance & Customer Analytics Dashboard

### Overview

This dashboard analyzes Apple retail sales and customer insights across multiple dimensions such as product category, profession, payment type, and city performance.

### Key Insights

* Revenue by Customer Profession
* Revenue by Product Category
* Revenue by Payment Type
* Accessory Revenue by Category
* Revenue Trends by City

## 👟 Adidas Sales Analysis Dashboard

### Overview

This dashboard provides a detailed analysis of Adidas sales performance across regions, cities, and product categories.

### Key Metrics

* **Total Sales**
* **Units Sold**
* **Operating Profit**
* **Profit Margin**

### Analysis Included

* City-wise Total Sales
* Sales by Region
* Product Margin Comparison
* Units Sold by State (Map Visualization)
